# Graad 7 Afrikaans FAL — Eksamenhersiening

A self-marking, iPad-friendly revision paper for Grade 7 Afrikaans FAL.

## Features
- 35 questions covering woordorde, voegwoorde, tydsvorme, ontkenning, vraagsinne, indirekte rede, and woordstrukture.
- Check one answer or the whole paper, with feedback and hints.
- Model answers available after repeated unsuccessful attempts.
- Saves progress locally in the browser.
- A4 printable worksheet.
- Everything runs from a single `index.html` file, without external dependencies.

## Publishing with GitHub Pages
In GitHub, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main`, `/(root)`, and **Save**.

After the deployment completes, open the GitHub Pages address shown in Settings → Pages.

## Notes for teachers
The marking accepts a curated set of valid answers and ignores minor punctuation and case differences. Learners may construct other correct Afrikaans sentences; teachers should review a response if an appropriate variation is marked incorrect.
